# furniture-website
My project is a furniture e-commerce website where users can browse and purchase customized furniture products. I developed this project using HTML, CSS, JavaScript for frontend and PHP with SQL for backend and database management.

I also integrated email functionality using PHPMailer for customer communication and order notifications. Additionally, I created an admin panel where the owner can manage products, view customer data, and update listings.

Through this project, I gained practical experience in full-stack development and database handling.
